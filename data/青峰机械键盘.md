【产品名称】青峰机械键盘
【版本号】75%配列版
【类别】电脑外设

# 1. 布局与轴体参数
采用 82 键精简 75% 布局，保留独立方向键和 F 键区，为鼠标留出更多桌面空间。
搭载全键热插拔 PCB 板，兼容市面上 99% 的 3 脚与 5 脚机械轴体。
原厂配置“青峰定制线性金轴”：触发压力 45g，触发行程 1.8mm，总行程 3.6mm，敲击声音沉闷（雨滴音），适合办公与游戏。

# 2. 三模连接方式
有线连接：将拨动开关拨至“USB”，使用 Type-C 线缆连接电脑，支持全键无冲。
2.4G 无线连接：开关拨至“2.4G”，将接收器插入电脑 USB 口， FN + 4 组合键进入配对状态。
蓝牙 5.0 连接：开关拨至“BT”，可同时记忆 3 台设备。长按 FN + 1/2/3 即可进行蓝牙配对与信道切换。

# 3. RGB 灯效调节
内置 18 种独立 RGB 背光灯效，底部配备半透明均光环绕灯带。
FN + \ 键：切换主键区灯效模式。
FN + 方向键上/下：增加或降低主键区背光亮度（共 5 档）。
FN + 方向键左/右：减慢或加快动态灯效的速度。

# 4. 常见问题 FAQ
Q：为什么我的键盘打字突然没有反应，但灯还在亮？
A：请检查是否误触了 FN + WIN 键导致 Windows 键被锁定，或者检查底部的连接模式拨动开关是否处在对应的档位。若使用蓝牙，请检查电脑蓝牙是否处于休眠状态。
Q：热插拔换轴有什么注意事项？
A：拔轴时请使用附赠的拔轴器，夹住轴体上下卡扣垂直拔出；插新轴时，务必对准 PCB 板孔位针脚垂直压入，切勿倾斜用力，以免针脚弯折。
